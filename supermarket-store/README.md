# Supermarket & Hypermarket Store — Independent Demo

هذه نسخة مستقلة مخصصة للسوبرماركت والهايبرماركت.

## مواقع النسختين
- مطاعم مجالس العرب: `premium-store/index.html` — فرع التطوير `feature/majalis-cart-detail-20261120`
- سوبرماركت وهايبرماركت: `supermarket-store/index.html` — فرع التطوير `feature/supermarket-hypermarket-store-20261121`

## آلية الفصل
1. لا يتم تعديل ملفات `premium-store/` عند تطوير نسخة التجزئة.
2. تُنفذ تعديلات نسخة التجزئة في الفرع `feature/supermarket-hypermarket-store-20261121` وبداخل `supermarket-store/` فقط.
3. نسختا المتجر تستخدمان مفاتيح تخزين محلي منفصلة للسلة والمفضلة والمنتجات الأخيرة وبيانات العميل؛ لذلك لا تختلط بياناتهما عند فتح الموقعين من نفس الأصل.
4. النسخة الجديدة صفحة HTML/CSS/JavaScript مستقلة، ولا تتطلب بناء Laravel أو خادمًا أو قاعدة بيانات حاليًا.
5. لتفادي نقل التعديلات بين النشاطين عن طريق الخطأ، لا تدمج فرعي التطوير قبل مراجعة المجلدات المستهدفة.

## ما تم إنجازه
- 12 قسمًا للسوبرماركت والهايبرماركت.
- 120 منتجًا تجريبيًا بأسعار وصور توضيحية.
- بنرات تسويقية وأقسام وواجهة تسوق مخصصة للتجزئة.
- البحث، المفضلة، تفاصيل المنتجات، السلة، الكميات، نموذج بيانات العميل، صفحات العروض والطلبات والحساب.
- التصميم RTL وتجاوب الجوال، مع الحفاظ على اعتماد خط DIN Next Arabic إن توفر محليًا.

## حدود النسخة
- بيانات المنتجات والأسعار والصور ليست بيانات تاجر فعلي.
- لا يوجد ربط مخزون أو باركود أو بوابة دفع أو إنشاء طلب حقيقي أو حساب مستخدم حقيقي.
- لا توجد بيانات جرد أو عروض خصم معتمدة.
- يجب تزويد بيانات التاجر وكتالوج المنتجات قبل الإطلاق الإنتاجي.
